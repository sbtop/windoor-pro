## 🎨 ESPECIFICACIONES VISUALES

### Paleta de Colores
- **Primario:** #6366f1 (Índigo)
- **Secundario:** #0ea5e9 (Sky blue)
- **Acento:** #10b981 (Emerald para éxitos/precios)
- **Neutral:** #f8fafc (Slate 50 para fondos)
- **Texto:** #0f172a (Slate 900)

### Tipografía
- **Títulos:** Inter o SF Pro Display, Bold, 24-48px
- **Cuerpo:** Inter o SF Pro Text, Regular/Medium, 14-18px
- **UI:** Sistema de fuente consistente con la app

### Efectos y Animaciones
- **Transiciones:** Fade in/out suaves (0.3s)
- **Hover:** Scale 1.05, sombra aumentada
- **Highlight:** Borde brillante alrededor del elemento
- **Cursor:** Siempre visible, movimientos naturales
- **Count up:** Números animados de 0 a valor final

### Iconografía
- **Estilo:** Lucide React (consistente con la app)
- **Tamaño:** 16-24px
- **Color:** Seguir paleta de colores

## 🎬 NOTAS DE PRODUCCIÓN

### Pre-producción
1. **Preparar entorno de demo:**
   - Limpiar dashboard de datos sensibles
   - Tener proyectos de ejemplo listos
   - Configurar datos de demo (precios realistas)
   
2. **Configurar grabación:**
   - Resolución: 1920x1080
   - FPS: 30 o 60
   - Cursor: Personalizado, visible
   - Zoom: Habilitado para detalles

### Durante la grabación
1. **Movimientos de cursor:**
   - Naturales, no demasiado rápidos
   - Pausas breves en elementos importantes
   - Trayectorias directas
   
2. **Timing:**
   - Seguir tiempos del storyboard
   - Permitir 2-3 segundos de margen por escena
   - No rush en demo complejas

3. **Audio:**
   - Voz en off: Clara, entusiasta, profesional
   - Música: Fondo suave, no competir con voz
   - Efectos: Sutiles (clicks, notificaciones)

### Post-producción
1. **Edición:**
   - Cortar silencios innecesarios
   - Alinear audio con visual
   - Agregar transiciones suaves
   
2. **Corrección de color:**
   - Asegurar consistencia
   - Resaltar elementos importantes
   - Mantener branding

3. **Exportación:**
   - Formato: MP4 (H.264)
   - Bitrate: 8-12 Mbps
   - Audio: AAC, 192kbps, 44.1kHz
